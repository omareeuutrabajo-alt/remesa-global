Remesa Global

Módulo de inicio de nivel fintech para una aplicación de remesas

En vivo

Autenticación completa de extremo a extremo: presentación, onboarding, registro, inicio de sesión, verificación por OTP, PIN de seis dígitos, biometría, recuperación de contraseña y verificación de identidad (KYC) con documento y selfie. El cliente es Flutter; el servidor, una API Express con JWT, rotación de refresh tokens, auditoría y control de dispositivos de confianza.

  • OTP de 6 dígitos con caducidad, límite de intentos y espera entre reenvíos
  • Rotación de refresh tokens con detección de reutilización: si un token robado se repite, caen todas las sesiones
  • PIN y biometría ligados al dispositivo mediante un token opaco revocable
  • KYC con subida de documento y selfie a un bucket privado y URLs firmadas de 5 minutos
  • Bloqueo progresivo de cuenta, registro de auditoría y límites de envío por nivel verificado
  • Base de datos sin acceso anónimo: RLS activo y permisos revocados para las claves públicas
Por quéLa pantalla de inicio es donde una aplicación financiera se gana o se pierde la confianza. Quería construir ese tramo con el mismo rigor que exige un banco: bloqueo por intentos, códigos de un solo uso, detección de reutilización de tokens y registro de cada acción sensible.
